# Visuels Bring Medina Home

Dépôt **public** : il ne sert qu'aux visuels destinés à être publiés.
Son seul rôle est de donner à chaque fichier une adresse web publique,
que Metricool et les réseaux sociaux savent lire.

- `posts/` — publications uniques
- `carrousels/` — vignettes de carrousel
- `videos/` — vidéos courtes (100 Mo maximum par fichier)

**Ne rien mettre ici qui ne soit pas destiné au public.**
Le dépôt du site, `bmhsite`, reste privé.
